# Дашборд PowerChute для Grafana

Файл для импорта: [`powerchute-exporter.json`](powerchute-exporter.json). Классическая JSON-модель Grafana, встроенные панели; ориентир — Grafana 10.4 и новее. Дополнительные плагины не нужны.

1. Настройте Prometheus на сбор `/metrics` экспортера. Пример `scrape_config` есть в основном README.
2. Добавьте этот Prometheus как data source в Grafana.
3. Откройте **Dashboards → New → Import → Upload dashboard JSON file**, выберите JSON и нажмите **Import**.
4. В верхней части дашборда выберите **Prometheus**, **Job**, **UPS / instance** и валюту.

Источник данных выбирается переменной `datasource`, поэтому UID вашего Prometheus не нужно вписывать в файл. Один дашборд показывает одну выбранную установку: напряжения и итоги разных ИБП не суммируются. Валюта берётся из label `currency`; конвертации нет.

Панели содержат HTTP-доступность экспортера, результаты сбора обоих источников, свежесть и время последней записи, заряд, нагрузку, напряжения, итоги Energy Reporting и диагностику ошибок/авторизации. По умолчанию выбраны последние 24 часа и обновление каждые 30 секунд.

Важно для интерпретации:

- Значения Data Log — последняя запись журнала; это не мгновенное состояние ИБП.
- Свежесть оценивается метрикой `powerchute_datalog_fresh`, учитывающей настройки экспортера. HTTP-доступность и успешное чтение журнала проверяются отдельно.
- Карточки запрашивают instant-значения. Истёкший TTL не маскируется выбором последнего значения за весь диапазон. Отсутствие данных не заменяется нулём, а пропуски на графиках не соединяются.
- Нагрузка выше 100% отображается без ограничения сверху. Цветовые пороги заряда/нагрузки относятся к дашборду и могут быть изменены в редакторе панелей.
- Период Grafana управляет отображаемой историей, но не периодом Energy Reporting. Его фактические From/To доступны в `/health`. Текущие энергия, стоимость и CO₂ — Gauge, а не счётчики; к ним не применяется `rate()` или `increase()`.
- Возраст последнего успешного сбора и возраст измерения Data Log — разные показатели.
- Счётчики в таблице ошибок накоплены с запуска процесса. Скорости ошибок и входов вычисляются только из служебных Counter-метрик.
- Отключённый источник также показывает «Нет данных». Если список валют пуст, Energy Reporting ещё не публиковал стоимость либо источник отключён.

Файл можно импортировать в Grafana без URL экспортера: Grafana обращается к Prometheus. Убедитесь, что Prometheus использует достаточный retention для нужной глубины истории и что в настройках data source правильно указан scrape interval для `$__rate_interval`.
